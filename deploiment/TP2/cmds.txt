>>>>>>>>>>>> LABELS <<<<<<<<<<<<<<<<<<<

Get all pods with all labels :
kubectl get pods --show-labels

Get with colones :
kubectl get pods -L app,env,tier

Get all boutique pods :
kubectl get pods -l app=boutique

Get all prod pods :
kubectl get pods -l env=prod

Get all frontend in dev environement pods :
kubectl get pods -l env=dev,tier=frontend

Get all not boutique pods :
kubectl get pods -l app!=boutique

Get all pods in dev / test env :
kubectl get pods -l 'env in (dev , test)'

Add label to boutique pods : 
kubectl label pods -l app=boutique version=1.0

Get all pods without version label
kubectl get pods -l '!version' --show-labels

Update version to 1.1 for only boutique-api-prod :
kubectl label pod boutique-api-prod version=1.1 --overwrite

Delete version label for all pods :
kubectl label pod --all version-

Display only pods name of backend:
kubectl get pods -l tier=backend -o name

Delete env label for blog-dev:
kubectl label pod blog-dev env-
